エラーメッセージには、失敗した操作の詳細が含まれます。エラーが返っても、すでに編集が保存されていることがあります。次の操作を決める前に、メッセージと現在のプロジェクトまたは出力ファイルを確認してください。

## headless-rough-cut-history-unconfirmed

`HEADLESS_ROUGH_CUT_HISTORY_UNCONFIRMED`

ラフカットの編集は**すでにコミットされています**が、実行または公開を裏付ける記録を返せませんでした。エラーにはプロジェクト、シーケンス、実行 ID、コミット済みのリビジョンが含まれます。そのまま再試行すると編集が重複するおそれがあります。まずプロジェクトと履歴を確認してください。

## analyzer-source-changed

`ANALYZER_SOURCE_CHANGED`

ローカル素材が指定されたダイジェストと一致しないか、解析中に素材が変化した、または読み取れなくなりました。この解析の結果は採用されません。素材とその登録情報を確認し、正しい内容とダイジェストで新たに解析してください。

## final-cut-native-search-timeout

`FINAL_CUT_NATIVE_SEARCH_TIMEOUT`

Final Cut Pro のブラウザを単独で検索する操作がタイムアウトしました。完全な検索結果は得られていません。この検索でタイムラインに変更は加わりません。Final Cut Pro とブラウザが利用できる状態か確認してから再検索してください。

## final-cut-native-search-unavailable

`FINAL_CUT_NATIVE_SEARCH_UNAVAILABLE`

ブラウザ内の子要素にアクセスできない、探索の深さが上限に達したなどの理由で、検索を完了できませんでした。この検索でタイムラインに変更は加わりません。検索結果が 0 件だったと判断せず、ブラウザの状態とプロバイダーの対応機能を確認してください。

## final-cut-sqlite-inspection-unavailable

`FINAL_CUT_SQLITE_INSPECTION_UNAVAILABLE`

標準サーバーには SQLite を調査するプロバイダーが設定されていません。この照会ではエディタの確定状態を取得できず、編集も行われません。エディタが対応する機能を使用してください。研究用の連携には、明示的に組み込んだ実験用プロバイダーと使い捨てのフィクスチャが必要です。

## headless-fcpxml-stale

`HEADLESS_FCPXML_STALE`

書き出し対象またはリビジョンが指定のプロジェクトと一致しなくなりました。要求は FCPXML の出力前に拒否されます。現在のプロジェクトとシーケンスのリビジョンを確認し、そのリビジョンで書き出しを準備し直してください。

## headless-render-unavailable

`HEADLESS_RENDER_UNAVAILABLE`

ヘッドレスのレンダラーと検証機能を利用できるように設定されていません。レンダリングは開始されず、このエラー自体で編集がコミットされることはありません。バックエンドの設定と対応機能を確認してください。

## headless-rough-cut-render-unavailable

`HEADLESS_ROUGH_CUT_RENDER_UNAVAILABLE`

ラフカットに必要なレンダラーと検証機能が使えないため、レンダリングを開始できません。現在のリビジョンを確認し、必要な機能を設定してから新しい操作を準備してください。

## fcpxml-unsupported-timeline-feature

`FCPXML_UNSUPPORTED_TIMELINE_FEATURE`

タイムラインに FCPXML で安全に表現できない機能が含まれているため、コンパイルが拒否されました。指摘された機能と現在のプロジェクトを確認し、対応範囲内のタイムラインを書き出すか、その機能への対応を待ってください。

## fcpxml-invalid-time

`FCPXML_INVALID_TIME`

時刻を表現できないか、コンパイラーの時間に関する制約に違反しているため、コンパイルが拒否されました。メッセージに示されたフィールドを確認し、時刻の分数表現やフレーム境界とのずれを修正してから書き出してください。

## capability-unavailable

`CAPABILITY_UNAVAILABLE`

選択したプロバイダーでは、要求した機能が提供または設定されていません。その操作は実行されません。複数段階の処理では、それ以前の操作の状態はこのコードだけでは判断できません。操作の詳細と現在の対象を調べ、`editing.route` または機能の照会で、対応している経路を選んでください。

## stale-context

`STALE_CONTEXT`

確認済みの状態や計画が現在の状態と一致しないため、要求は拒否されました。複数段階の操作では、それまでに実行された処理の詳細を確認してください。対象とリビジョンを取得し直し、新しい計画を作成して承認してください。

## headless-rough-cut-render-failed

`HEADLESS_ROUGH_CUT_RENDER_FAILED`

レンダリング結果が検証に通りませんでした。実行記録は保存され、その識別子がエラーに含まれます。ラフカットの編集はコミット前ですが、出力ファイルが残っている場合があります。記録と出力を確認し、報告された問題を修正してから再試行してください。

## headless-storyboard-unsupported

`HEADLESS_STORYBOARD_UNSUPPORTED`

ストーリーボードのレンダラーが対象のタイムラインから画像を取得できません。ラフカットのプレビューでほかの処理が成功した場合は、ストーリーボードを利用できない旨とともに JSON プレビューと承認情報が返ります。プレビューで編集はコミットされません。JSON の内容を確認し、意図した操作を判断するのに十分な場合のみ、そのプレビューを利用してください。

## headless-storyboard-limit

`HEADLESS_STORYBOARD_LIMIT`

要求したストーリーボードがサンプリングの上限を超えています。ラフカットのプレビューでほかの処理が成功した場合は、ストーリーボードを利用できない旨とともに JSON プレビューと承認情報が返ります。プレビューで編集はコミットされません。JSON の内容を確認するか、対象範囲を絞ってから次の操作を決めてください。

## headless-undo-unverified

`HEADLESS_UNDO_UNVERIFIED`

`headless.edit.undo` は復元後のリビジョンを保存しましたが、独立した読み戻しではリビジョンとタイムラインを検証できませんでした。取り消しが成功したと判断したり、続けて Undo を実行したりしないでください。プロジェクトと現在のリビジョンを再取得し、タイムラインを意図した状態と照合してから、必要な操作を準備してください。
