## Framekit とは

Framekit はローカル環境で動作する動画編集ランタイム兼 MCP サーバーです。MCP クライアントから利用可能な操作を調べ、Framekit が管理するプロジェクトとタイムラインを編集できます。メディアの解析、レンダリング、Final Cut Pro との連携もこのモデルを介して行います。

## 用途に合わせて始める

- **手元のメディアを編集する** — Final Cut Pro のインストールや起動は不要です。[ヘッドレス編集](/ja/docs/headless-editing/)を参照してください。
- **Final Cut Pro と連携する** — Workflow Extension を設定して接続します。使える操作はプロバイダーが報告する機能によって異なります。[Final Cut Pro](/ja/docs/final-cut-pro/)で確認してください。
- **Framekit を開発する** — リポジトリから、毎回同じテストデータで動くサーバーを起動できます。[フィクスチャのセットアップ](/ja/docs/getting-started/)を参照してください。

初めて使う方は[インストール](/ja/docs/installation/)から[クイックスタート](/ja/docs/quick-start/)へ進んでください。フィクスチャでの実行結果や FCPXML の出力だけでは、Final Cut Pro で開いているタイムラインに変更が反映されたかは確認できません。
