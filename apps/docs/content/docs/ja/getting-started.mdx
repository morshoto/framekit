## フィクスチャサーバーを起動する

Node.js 22.23.5 と pnpm 12.18.0 を用意し、リポジトリのルートで実行します。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run mcp
```

サーバーはメモリ上の固定テストデータを使い、標準入出力（stdio）で MCP クライアントと通信します。標準出力にはプロトコルメッセージが流れます。クライアントからこのプロセスに接続し、`connection.status`、`editor.inspect`、`editing.route` でバックエンドが対応する操作を調べてください。

## 応答を確認する

別のターミナルを開き、リポジトリのルートで実行します。

```sh
pnpm run smoke:fixture-mcp
```

このコマンドは検証専用のフィクスチャサーバーを起動して接続を確認します。成功すると `Fixture MCP stdio smoke passed: connection.status ready.` と表示されます。最初に起動したサーバーは Ctrl+C で終了できます。

## チェックアウトを検証する

```sh
pnpm run test
pnpm run check:boundaries
pnpm run check:docs
```

フィクスチャの設定と任意の Nix プロファイルは[セットアップガイド](https://github.com/morshoto/framekit/blob/main/docs/getting-started.md)を参照してください。フィクスチャでの成功だけでは、Final Cut Pro での編集結果は確認できません。
