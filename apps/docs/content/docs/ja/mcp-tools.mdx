## 利用可能な機能を調べる

MCP クライアントに表示されるツール一覧と各ツールの入力スキーマで、現在のインターフェースを確認できます。まず `connection.status` で接続を診断し、`editor.inspect` でバックエンドの機能を調べ、`editing.route` で目的の操作に使える経路を確認してください。`CAPABILITY_UNAVAILABLE` は選択した操作が利用できないことを示します。ほかの機能が使えるかどうかは個別に確認してください。

## 主な使い方

- ヘッドレス用のツールで、Framekit が管理するプロジェクトを作成し、開いて内容を確認・編集できます。変更前にリビジョンを確認し、プレビューしてから実行します。
- スキルは `skill.list`、`skill.inspect`、`skill.preview`、`skill.execute` で扱います。選んだ候補を、プレビューした対象とリビジョンに対して実行してください。
- ネイティブ操作の復旧状態を照会すると、記録済みの情報が返ります。チェックポイントは解除されず、実行中の操作がすべて終了したかどうかも、この照会だけでは判断できません。

ツールの提供状況と必要な入力は、実行中のサーバーで確認できます。操作を選ぶ前に[ヘッドレス編集](/ja/docs/headless-editing/)と [Final Cut Pro](/ja/docs/final-cut-pro/) を参照してください。
