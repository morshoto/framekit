## プロジェクトとタイムライン

Framekit プロジェクトは、エディタに依存しない形式で編集状態を保持します。タイムラインの中間表現（Timeline IR）では、シーケンスとタイムライン上の各配置（オカレンス）に安定した ID を割り当て、時刻をフレーム単位で正確に扱える有理数で表します。アダプターがこのモデルと FCPXML などの外部形式を相互に変換します。

## 操作対象とリビジョン

対象を特定するには、プロジェクト、シーケンス、リビジョンを指定し、個々の配置を扱う操作ではオカレンスも指定します。`playheadTime` はエディタの再生ヘッドの位置です。移動するため、対象の ID の代わりには使えません。プロジェクトのリビジョンと履歴のコミットは別々に管理されます。編集前とレンダリング前に現在のリビジョンを確認してください。

[リビジョンと安全性](/ja/docs/revisions-and-safety/)と[状態・識別子・リビジョンの仕様](https://github.com/morshoto/framekit/blob/main/docs/architecture.md#state-identity-and-revisions)を参照してください。
