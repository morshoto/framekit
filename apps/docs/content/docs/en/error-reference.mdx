Error messages contain details specific to the failed operation. Inspect those details and the current project or artifact before deciding what to do next. A failed response does not always mean that an edit was rolled back.

## headless-rough-cut-history-unconfirmed

`HEADLESS_ROUGH_CUT_HISTORY_UNCONFIRMED`

The rough-cut project edit has **already committed**, but execution or publish proof could not be returned. The error includes the project, sequence, execution ID and committed revision. Reinspect the project and its history before deciding whether any further action is needed; blindly retrying may duplicate an edit.

## analyzer-source-changed

`ANALYZER_SOURCE_CHANGED`

A local source did not match the supplied digest, or changed or became unreadable while analysis ran. No result from that analysis is accepted. Reinspect the source and its binding, then run a new analysis with the correct content and digest.

## final-cut-native-search-timeout

`FINAL_CUT_NATIVE_SEARCH_TIMEOUT`

The standalone Final Cut Browser search exceeded its deadline. The search has no complete result; it does not commit a timeline edit. Check Final Cut and Browser availability before retrying the search.

## final-cut-native-search-unavailable

`FINAL_CUT_NATIVE_SEARCH_UNAVAILABLE`

Framekit could not establish a complete Browser search, for example because a descendant was inaccessible or traversal reached its depth limit. No complete search result is available and no timeline edit is committed by the search. Inspect the Browser and provider capabilities; do not treat the response as an empty result.

## final-cut-sqlite-inspection-unavailable

`FINAL_CUT_SQLITE_INSPECTION_UNAVAILABLE`

The standard server has no SQLite inspection provider configured. This observation did not produce canonical editor evidence or commit an edit. Use supported editor capabilities; research integrations require an explicitly injected experimental provider and disposable fixtures.

## headless-fcpxml-stale

`HEADLESS_FCPXML_STALE`

The export target or revision no longer matches the requested project. The stale request is rejected before FCPXML export. Inspect the current project and sequence revision, then prepare a new export for that revision.

## headless-render-unavailable

`HEADLESS_RENDER_UNAVAILABLE`

The headless renderer and verifier are not configured. The render cannot start; this error does not itself commit a project edit. Check the configured backend and available capabilities before requesting a render again.

## headless-rough-cut-render-unavailable

`HEADLESS_ROUGH_CUT_RENDER_UNAVAILABLE`

The rough-cut workflow requires a configured renderer and verifier, but they are unavailable. Rendering cannot start. Inspect the current project revision and configure the required capabilities before preparing another operation.

## fcpxml-unsupported-timeline-feature

`FCPXML_UNSUPPORTED_TIMELINE_FEATURE`

The requested timeline contains a feature the FCPXML compiler cannot safely represent. Compilation is rejected. Inspect the reported feature and the current project; use a supported timeline or wait for support before exporting again.

## fcpxml-invalid-time

`FCPXML_INVALID_TIME`

A time value cannot be represented or violates the compiler's time constraints. Compilation is rejected. Inspect the field named in the message and correct the rational time or frame alignment before exporting again.

## capability-unavailable

`CAPABILITY_UNAVAILABLE`

The selected provider does not advertise or configure the requested capability. The requested capability is not performed; this code alone does not establish the state of earlier actions in a multi-step workflow. Inspect the operation details and current target, then use `editing.route` or capability inspection to select a supported workflow.

## stale-context

`STALE_CONTEXT`

The inspected context or plan no longer matches the current state. The stale request is rejected; check the operation's details for any earlier work in a multi-step workflow. Reinspect the target and revision, then prepare and approve a new plan.

## headless-rough-cut-render-failed

`HEADLESS_ROUGH_CUT_RENDER_FAILED`

Render verification did not pass. A render record is saved and the error identifies it; the rough-cut project edit has not reached its commit step, but a render output may exist. Inspect the render record and output before correcting the reported problem and preparing a new attempt.

## headless-storyboard-unsupported

`HEADLESS_STORYBOARD_UNSUPPORTED`

The storyboard renderer cannot sample the requested timeline. In rough-cut preview this is reported as storyboard unavailability alongside the JSON preview and approval when the remaining preview succeeds; preview does not commit the edit. Inspect the JSON preview and use it only if it provides enough evidence for the intended operation.

## headless-storyboard-limit

`HEADLESS_STORYBOARD_LIMIT`

The requested storyboard exceeds a sampling limit. In rough-cut preview this is reported as storyboard unavailability alongside the JSON preview and approval when the remaining preview succeeds; preview does not commit the edit. Inspect the JSON preview or reduce the requested scope before deciding how to proceed.
