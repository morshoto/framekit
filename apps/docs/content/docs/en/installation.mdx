## Choose your requirements

- **Using the published package:** Node.js 20 or newer. The Codex plugin starts the package with `npx`.
- **Developing from a checkout:** Node.js 22.23.5 and pnpm 12.18.0. See [Development](/en/docs/development/).
- **Building the native extension:** Xcode 16.4 and the macOS 15.5 SDK, in addition to the contributor tools. These are not required for headless use.

## Install the Codex plugin

Add the marketplace once:

```sh
codex plugin marketplace add morshoto/framekit
```

Open `/plugins` in Codex, install **Framekit**, and start a new Codex session. A checkout is not required.

## Optional: connect Final Cut Pro

The Final Cut Workflow Extension is a separate release asset. When you need a live connection, obtain it from a matching [GitHub release](https://github.com/morshoto/framekit/releases); see [Final Cut Pro](/en/docs/final-cut-pro/) for connection and capability details.

Continue to [Quick Start](/en/docs/quick-start/) to check your connection.
