This reproducible example generates synthetic media, edits a disposable Framekit-owned project through the production MCP server, and checks a rendered MP4. It does not open Final Cut Pro. The commands run a checkout-based release-gate example; they are separate from the installed Codex plugin. See [Installation](/en/docs/installation/) for the plugin and supported runtime requirements.

## Prerequisites

Use macOS with Node.js 22.23.5, pnpm 12.18.0, Git, and FFmpeg/ffprobe available on `PATH`. FFmpeg needs `libx264`, AAC and the filters used by the [fixture generator](https://github.com/morshoto/framekit/blob/2f6f03b6a0cba5b5cb5d4a3ea0f44c3ffa9cdf6c/scripts/generate-headless-render-fixtures.mjs). A suitable system font is also needed for the title. The release-gate command and probe below passed in a fresh local checkout using the existing pnpm store on macOS 26.5.1 with FFmpeg 9.0.2 and candidate commit `2f6f03b6a0cba5b5cb5d4a3ea0f44c3ffa9cdf6c` (v0.2.6); it is not evidence of a published v0.2.6 package.

## Run the disposable example

Create a new directory and checkout; the test uses its own temporary project and generates red, blue, and green video and sine tones with FFmpeg. No third-party media is downloaded. The generator and manifest are part of the [Framekit repository](https://github.com/morshoto/framekit/tree/2f6f03b6a0cba5b5cb5d4a3ea0f44c3ffa9cdf6c). The repository does not currently declare a license for these files; their redistribution terms have not been established. Output encoding can differ by FFmpeg version, so the MP4 does not have a fixed checksum.

```sh
git clone https://github.com/morshoto/framekit.git framekit-first-video
cd framekit-first-video
git checkout --detach 2f6f03b6a0cba5b5cb5d4a3ea0f44c3ffa9cdf6c
pnpm install --frozen-lockfile
mkdir -p "$PWD/first-video-output"
FRAMEKIT_HEADLESS_RELEASE_GATE_EVIDENCE_DIR="$PWD/first-video-output" pnpm exec tsx --test tests/release/gate/headless-release-gate.test.ts
```

The test should report `ok 1` and `# fail 0`. It starts the production stdio MCP server, creates an empty timeline, registers generated sources, previews and executes an insertion, and adds a second source, titles and a transition. It reopens the project and renders the current revision. The test includes additional safety checks; its recorded tool transcript and observations are in `first-video-output/headless-release-gate-evidence.json`. Paths in that file may reveal local information; sanitize it before sharing. It also saves `verified-final.mp4` and `fixture-manifest.json`.

## Prompt for an MCP-capable assistant

The following prompt describes the same disposable task, but its end-to-end execution through Codex has **not yet been verified** for this candidate. The tested checkout command above is currently the reproducible path.

```text
Use Framekit with a new disposable headless project. Generate the repository's synthetic red and blue sample sources, inspect their registered IDs and the current project revision, and preview a two-shot edit. Show me the proposed timeline and wait for approval before executing. After approval, execute the reviewed edit, render an MP4 to a new path, and inspect the result with ffprobe. Report the revision, output path, and verification results. Do not open or modify Final Cut Pro.
```

The assistant should use the running server's tool schemas, keep each returned revision, and stop if the selected renderer or any required capability is unavailable. The prompt does not by itself establish that an assistant performed the requested calls.

## Inspect and verify

Open `first-video-output/verified-final.mp4` in a player. This frame is from the candidate run's actual output:

![Red frame from the rendered sample video](/images/first-video-output.png)

Independently inspect the result:

```sh
ffprobe -v error -show_entries stream=codec_type,width,height,r_frame_rate,sample_rate,channels -show_entries format=duration -of json first-video-output/verified-final.mp4
```

The observed run had a 320 × 180 video at 30/1 frames per second, mono audio at 48000 Hz, and a duration of 2.000000 seconds. The test also compares timeline state and checks output samples. Probe metadata alone does not prove the visual edit, audio content, or future results on a different environment.

## If something fails

Check the first failing message and installed versions. Missing FFmpeg, encoder, font, or renderer capability can prevent a render. Consult the [Error Reference](/en/docs/error-reference/) for coded errors and the [Troubleshooting](/en/docs/troubleshooting/) for symptom-based guidance. The sample produces a headless MP4; FCPXML is a separate handoff artifact, and neither proves an import, playback, or edit in Final Cut Pro.
