## What is Framekit?

Framekit is a local-first video editing runtime and MCP server. It lets an MCP client inspect capabilities and work with a Framekit-owned project and timeline. Integrations connect that model to media, rendering, and Final Cut Pro.

## Choose a path

- **Headless editing** works with Framekit-owned projects without opening or installing Final Cut Pro. See [Headless Editing](/en/docs/headless-editing/).
- **Final Cut Pro** connects to an explicitly configured Workflow Extension. Available operations depend on the provider and its reported capabilities. See [Final Cut Pro](/en/docs/final-cut-pro/).
- **Contributors** can start a deterministic fixture server from a checkout. See [Fixture setup](/en/docs/getting-started/).

Start with [Installation](/en/docs/installation/) and [Quick Start](/en/docs/quick-start/). Fixture results and FCPXML artifacts do not prove that a live Final Cut timeline changed.
