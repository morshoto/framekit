## Run the fixture server

For development, install Node.js 22.14.0 and pnpm 12.18.0, then from the repository root:

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run mcp
```

The server uses a deterministic in-memory fixture and communicates over stdio. Connect an MCP client to the process; stdout is the protocol stream, not an interactive shell. Use `connection.status`, `editor.inspect`, and `editing.route` to inspect what the selected backend supports.

## Confirm the fixture responds

In a separate terminal, from the repository root, run:

```sh
pnpm run smoke:fixture-mcp
```

The command starts an isolated fixture server and checks its connection. A successful run prints `Fixture MCP stdio smoke passed: connection.status ready.` You can stop the server started above with Ctrl+C when you are done.

## Validate a checkout

```sh
pnpm run test
pnpm run check:boundaries
pnpm run check:docs
```

For fixture-focused setup and optional Nix profiles, see the [maintained getting-started guide](https://github.com/morshoto/framekit/blob/main/docs/getting-started.md). Fixture behavior is not proof of a native Final Cut edit.
