## Start with the shortest path

Install FrameKit, choose an editor backend, connect your agent, inspect the
advertised capabilities, and make the first supported operation. You do not
need to understand the runtime architecture before reaching that first result.

## Go deeper when you need to

The canonical repository documentation covers Final Cut integration, MCP tools,
runtime architecture, product requirements, design decisions, and the validation
evidence behind capability claims. The public wiki adds navigation and context;
it does not replace those source documents.
